# screenshot-pdf

🔗 https://screenshot-pdf.pages.dev/

## このツールについて

- スマホのスクショなど、複数の画像をA4のPDFにまとめてメール・チャットで送るツールです。オフライン版も用意しています。
- スマホでの利用を想定しています（「ファイルを保存してから添付する」ではなく、その場でメール・チャットの送信先を選べます）。
- **処理はすべてローカルで完結し、画像もPDFもサーバーに送信されません。**
- 公開は Cloudflare Pages を利用しています。

## 使い方

1. 「スクショを選ぶ」で画像を選択する（選ぶたびに追加されます。最大40枚。やり直すときは「全部やり直す」）
2. A4ページの割り付けプレビューが出るので確認する（1ページに4枚・2×2）
   - 並び順は選択順です。各コマの◀▶で1つ前・後ろと入れ替えられ、×ボタンでその1枚を除外できます
   - 並べ方は「N型」（左上→左下→右上→右下）の固定です
3. 必要なら「軽量化する」をオンにする（メール・LINEで送れない大きさのときに。元より小さくなる画像だけが対象です）
4. 「PDF作成」でA4 PDFを生成する
5. 「PDF共有」（対応ブラウザ。OSの共有シートが開く）または「PDF保存」（非対応ブラウザでは最初からこちらの表示になる）で送信・保存する

X（Twitter）などのアプリ内ブラウザでは、ファイル選択・共有・保存が動かないことがあります。開いたときに案内ダイアログ（初回のみ）が出るので、その指示に従って通常のブラウザで開き直してください。

## 仕組み（ブラウザ完結）

- 選んだ画像は `pdf-lib` でA4ページ（2×2グリッド、余白24pt・すき間16pt）に配置し、新しいPDFを生成します。
  - PNG/JPEGはそのまま無劣化で埋め込みます。それ以外の形式（WebP等）は一度canvasでPNGに変換してから埋め込みます。
  - EXIFの回転情報つきのJPEG（スマホで撮った写真など）は、`pdf-lib` が回転を無視するため、canvasで回転を適用してから埋め込みます（プレビューと向きを揃えるため）。
  - 「軽量化する」は、長辺1600pxのJPEG（品質0.82）を試し、**元ファイルより小さくなった場合だけ**採用します。
  - 各画像はセル内にアスペクト比を保ったまま収めます（はみ出た分をトリミングはしません＝余白ができることがあります）。
  - 各コマの左上には選択順の番号（プレビューと同じ丸バッジ）を書き込みます。印刷・保存後も何枚目のスクショかが分かるようにするためです。
  - PDF全体をメモリ上で組み立てるため、枚数は最大40枚に制限しています。
- 「PDF共有」は Web Share API（`navigator.share`）を使い、対応ブラウザではOS標準の共有シート（メール・LINE等）を呼び出します。
  - 対応：Android Chrome、iOS Safari など（想定する主な利用環境）。**非対応：デスクトップFirefox（全バージョン）など。**
  - 非対応ブラウザでは、ボタンの表示が最初から「PDF保存」に切り替わります（自動フォールバック）。共有に失敗した場合も保存に切り替わり、その旨が表示されます。
  - HTTPS（またはlocalhost）が必須の機能のため、オフライン版をfile://で直接開いた場合も自動的に保存動作になります。
- React / Next.js は使用していません（素のHTML＋バニラJSで実装しています）。
- `pdf-lib`（1.17.1）は外部CDNではなく同一ドメインから配信します（`public/pdf-lib.min.js`）。ページを開いても外部への通信は発生しません。
- アイコンは Bootstrap Icons（MIT License）から使う分だけSVGをそのまま埋め込んでいます。CDN・Webフォントは不使用です。詳細は [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。

仕組みの詳しい解説（図つき）は、[技術解説ページ](https://minnanosaiban.github.io/tomo/tech/screenshot-pdf/)にあります。

## オフライン版

- `pdf-lib` を含めて全部を1枚のHTMLに埋め込んでおり、**保存後はネット接続なしで動作します**。
- ソースはテキストエディタでそのまま読めるため、処理内容をご自分の目で確認いただけます。
- `scripts/build-offline.js` が `public/index.html` + `public/app.js` + `vendor/pdf-lib.min.js` から自動生成します
  （ロジックは公開版と共通で、手作業での二重管理はしていません）。
- `npm run build:offline` で再生成できます（`npm run dev` / `npm run deploy` 実行時にも自動で実行されます）。
- 同じスクリプトが `vendor/pdf-lib.min.js` を `public/pdf-lib.min.js` にもコピーします（公開版が同一ドメインから読み込むため）。`python -m http.server` などで直接開く場合も、先に一度実行してください。
- `vendor/` の中身を更新したとき（pdf-lib のバージョンアップ等）は、再生成を忘れないようにしてください。
- `index.html` の文言を変えて、スクリプトの置換対象が見つからなくなったときは、黙って通さずエラーで止まります（`build-offline.js` 側の文言も合わせて直してください）。
- オフライン版はfile://で開くため、送信ボタンは常に保存動作になります（上記「仕組み」参照）。

## ローカルで動かす

```bash
npm install          # wrangler を入れる
npm run dev           # http://localhost:8788 で確認
```
`python -m http.server -d public 8000` でも構いません。

## 公開（Cloudflare Pages）

```bash
npm run deploy       # wrangler pages deploy
```
本人・関係者限定にする場合は、Cloudflare Access（Google ログイン）を前段に設定してください。

## 運用上の注意

- 入力画像・出力PDFは `.gitignore` で除外済みです。**個人情報を含む画像・PDFはコミット・pushしないでください。**
