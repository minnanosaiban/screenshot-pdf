# screenshot-pdf

## このアプリについて

- スマホのスクショなど、複数の画像をA4のPDFにまとめてメール・チャットで送るアプリです。オフライン版も用意しています。
- スマホでの利用を想定しています（「ファイルを保存してから添付する」ではなく、その場でメール・チャットの送信先を選べます）。
- **処理はすべてブラウザ内で完結し、画像もPDFもサーバーに送信されません。**
- 公開は Cloudflare Pages を利用しています。

## 使い方

1. 「🖼 スクショを選ぶ」で画像を複数選択する（選択ダイアログで返ってきた順のまま並びます。並べ替え非対応）
2. 右側にA4ページの割り付けプレビューが出るので確認する（1ページに4枚・2×2、はみ出す1枚は「✕」で除外できる）
3. 「PDFを作成」でA4 PDFを生成する
4. 「✉️ メール・チャットで送る」（対応ブラウザ）または「⬇ PDFを保存」（非対応ブラウザでは自動的にこちらの表示になる）で送信・保存する

## 仕組み（ブラウザ完結）

- 選んだ画像は `pdf-lib` でA4ページ（2×2グリッド）に配置し、新しいPDFを生成します。
  - PNG/JPEGはそのまま無劣化で埋め込みます。それ以外の形式（WebP等）は一度canvasでPNGに変換してから埋め込みます。
  - 各画像はセル内にアスペクト比を保ったまま収めます（はみ出た分をトリミングはしません＝余白ができることがあります）。
- 「メール・チャットで送る」は Web Share API（`navigator.share`）を使い、対応ブラウザではOS標準の共有シート（メール・LINE等）を呼び出します。
  - 対応：Android Chrome、iOS Safari など（想定する主な利用環境）。**非対応：デスクトップFirefox（全バージョン）など。**
  - 非対応ブラウザでは、ボタンの表示が最初から「⬇ PDFを保存」に切り替わります（自動フォールバック）。
  - HTTPS（またはlocalhost）が必須の機能のため、オフライン版をfile://で直接開いた場合も自動的に保存動作になります。
- React / Next.js は使用していません（素のHTML＋バニラJSで実装しています）。

## オフライン版

- `pdf-lib` を含めて全部を1枚のHTMLに埋め込んでおり、**保存後はネット接続なしで動作します**。
- ソースはテキストエディタでそのまま読めるため、処理内容をご自分の目で確認いただけます。
- `scripts/build-offline.js` が `public/index.html` + `public/app.js` + `vendor/pdf-lib.min.js` から自動生成します
  （ロジックは公開版と共通で、手作業での二重管理はしていません）。
- `npm run build:offline` で再生成できます（`npm run dev` / `npm run deploy` 実行時にも自動で実行されます）。
- `vendor/` の中身を更新したとき（pdf-lib のバージョンアップ等）は、再生成を忘れないようにしてください。
- オフライン版はfile://で開くため、送信ボタンは常に保存動作になります（上記「仕組み」参照）。

## ローカルで動かす

```bash
npm install          # wrangler を入れる
npm run dev           # http://localhost:8788 で確認
```
`python -m http.server -d public 8000` でも構いません。

## 公開（Cloudflare Pages）

```bash
npm run deploy       # wrangler pages deploy
```
本人・関係者限定にする場合は、Cloudflare Access（Google ログイン）を前段に設定してください。

## 運用上の注意

- 入力画像・出力PDFは `.gitignore` で除外済みです。**個人情報を含む画像・PDFはコミット・pushしないでください。**
